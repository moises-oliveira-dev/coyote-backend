# Coyote Backend

Projeto de estudo full stack, desenvolvido com objetivo didático, inicialmente focado no back-end e futuramente expandido para o front-end. O objetivo é desenvolver uma aplicação web funcional utilizando a arquitetura MVC (Model-View-Controller), aplicando conceitos de desenvolvimento web, organização de código, APIs e integração entre back-end e front-end.

## Estrutura do projeto 
````
api/
├── docker-compose.yml
├── package.json
├── tsconfig.json
└── src/
    ├── server.ts
    ├── routes/       → user.route.ts
    ├── controllers/  → user.controller.ts
    ├── services/     → user.service.ts
    ├── mocks/        → user.mock.ts
    └── types/        → user.type.ts
```
